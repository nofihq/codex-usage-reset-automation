# Contributing

Keep the setup limited to native Dot cloud tasks and one saved Plus browser
session. Use placeholders in public examples and keep credentials and private
run records out of the repository.

Check Markdown links and review changes against the verification steps in
[README.md](README.md). Task timing, source classification and duplicate handling
need dry checks. Activation and scheduling changes also need an observed native
run. Record test outcomes privately and distinguish live results from simulations.
